# Resume Projects

A collection of browser-based projects. Each project folder contains its own README with project-specific features, setup instructions, and scripts.

## Projects

### [DreadVault](./DreadVault/)

A cinematic horror game discovery library powered by the RAWG Video Games API. Browse, search, compare, and organize horror games, explore trailers and screenshots, and personalize the experience with Fog, Blood, and Eldritch themes.

- **Stack:** React, React Router, Tailwind CSS, Framer Motion, Axios
- **Live site:** [dreadvault.vercel.app](https://dreadvault.vercel.app)
- **Project guide:** [DreadVault README](./DreadVault/README.md)

### [FretLab](./FretLab/)

A guitar practice toolkit with an in-browser tuner, metronome, Circle of Fifths, scale library, and playable chord library. Audio playback and microphone pitch detection use browser APIs.

- **Stack:** React 18, TypeScript, Vite, Tailwind CSS, Web Audio API
- **Live site:** [fretlab.vercel.app](https://fretlab.vercel.app)
- **Project guide:** [FretLab README](./FretLab/README.md)
